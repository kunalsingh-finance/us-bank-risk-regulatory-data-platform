# Data Redistribution Policy

## Publicly included

- Deterministic synthetic institution-quarter records generated by project code.
- Frozen aggregate validation, uncertainty, subgroup, reconciliation, and language-control reports reviewed for institution-level disclosure.
- Project-authored configurations, schemas, field mappings, SQL, tests, and source-download logic.
- Official FDIC source URLs and documented hashes of frozen local evidence.

## Intentionally excluded

- Copied FDIC bulk CSV, API-response archives, definitions, and spreadsheets.
- Full 698,804-row financial panel and full 18.4-million-row peer table.
- Real institution-level model-development datasets, predictions, watchlists, drivers, and false-alert examples.
- DuckDB files, model binaries, local logs, caches, and source workbooks.

Explicit redistribution permission for the copied source artifacts was not established in the reviewed official pages. Exclusion is therefore the release default. Users may retrieve current data directly from FDIC BankFind Suite under the source's current terms and rebuild locally. Synthetic records are marked `DEMONSTRATION_ONLY`, use reserved identifiers, and must not be represented as actual institutions.

The project license does not license or change the terms of any source dataset.
