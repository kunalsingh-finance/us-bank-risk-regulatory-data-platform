# Phase 7 Public-Release Readiness

Final verdict: **Approved with dashboard restrictions**.

1. The dashboard is clearly a relative ranking tool rather than a calibrated likelihood model.
2. Probability, regulatory, guaranteed-outcome, and investment claims are excluded or explicitly negated.
3. All tiers derive from same-quarter percentiles.
4. The latest watchlist uses the frozen top-5% rule.
5. Drivers reproduce frozen scores and use bank-quarter-specific perturbations.
6. Peer comparisons match CERT, RSSDID, feature, and reporting quarter.
7. Feature and peer warnings are visible.
8. Weak calibration is prominent.
9. Time and asset-band instability are prominent.
10. Captured, missed, and false-positive examples are shown.
11. Displayed metrics reconcile exactly to Phase 5.
12. The app runs only from prepared presentation data.
13. Build and representative page performance are acceptable on the tested Windows desktop.
14. The language scan has zero unresolved findings.
15. The dashboard is suitable for a controlled recruiter demonstration with the persistent disclaimer.
16. Raw FDIC downloads and API archives must remain excluded pending redistribution review.
17. Serialized model and calibrator binaries should remain excluded from a public repository.
18. Aggregate validation reports and small metadata tables may be candidates for publication after review.
19. Bank-level scores, drivers, histories, peer comparisons, and watchlists require aggregate or synthetic samples for public distribution.
20. Absolute local paths, usernames, timestamps that reveal local context, and machine-specific metadata must be removed.
21. Final README navigation, clean-clone instructions, licensing review, and publication-safe screenshots still need editing.
22. Phase 7 public-release preparation may begin under these restrictions; no publication is authorized by this report.
