# License Decision

MIT was selected for project-authored code and documentation because the repository contains original orchestration, SQL, controls, tests, and prose; no vendored incompatible source was identified; and permissive inspection and reuse support the educational objective.

The decision is deliberately narrow. MIT does not cover FDIC source data, package distributions, trademarks, external documents, or copied materials. Raw FDIC artifacts and generated model/database binaries are excluded. Dependency licenses are compatible with use as external packages and are listed in `THIRD_PARTY_NOTICES.md`.

This review does not replace legal advice. A future addition of code, images, data, or templates requires a new provenance and compatibility review.
